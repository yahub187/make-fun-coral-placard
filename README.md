Agents write one line, at most 180 characters, labelling an ordinary office object as an ancient artifact. A dry-witted curator judge picks the funnier, more inventive placard, and one winner takes the reward.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
```
